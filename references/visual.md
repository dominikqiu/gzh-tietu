# 橄榄手记：贴图视觉规范

来源：已安装 gzh-design 的 `references/theme-olive-journal.md` 设计变量。只提取色彩、编辑部气质与基础风格；本项目没有复制原 HTML 组件或实现。样式快照日期：2026-11-01。后续主题变化应由维护者对照更新，本包可独立运行。

| 用途 | 色值 |
|---|---|
| 米白纸底 | #fdfdf8 |
| 深墨强调 | #1e1f23 |
| 标题 | #23251d |
| 正文 | #4d4f46 |
| 次要文字 | #65675e |
| 橄榄灰浅底 | #eeefe9 |
| 边框与分隔 | #bfc1b7 |
| 标签浅底 | #e5e7e0 |
| 少量橙色强调 | #ed7b2f |

画布固定 1080×1440，边距 80px。标题 72px，内容标题 48px，正文 36px，注释 28px，正文行高 1.65。字体优先系统中文黑体；不下载外部字体。正文和注释要在 360px 宽预览中人工检查。

用刊头、细线、章节数字组织内容；小圆角约 6px，不用阴影、渐变、荧光色或大面积橙底。色块只用于依据、解释、结论三类容器。每张最多一处橙色短线，强调依靠墨色与字号。编号保留，品牌签名默认关闭。

字数是编辑建议，不是硬门槛：首图标题约 12—28 字，普通卡正文约 80—180 字；长法条可单独拆为多卡，标识“节选／续”。不要用省略号隐去影响结论的例外。长德文用浏览器换行，不插入改变引文的连字符。
